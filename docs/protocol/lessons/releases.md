# Релизная дисциплина

Источник — **APT** (публикуемая библиотека, GitHub Actions, self-hosted GPU-раннеры); общие
пункты подтверждены **CPM**. Это не протокол, но в обоих деревьях это стоило денег.

**Слово владельца.**
- Push, tag и publish — каждый раз отдельное слово владельца. После сжатия контекста
  сверяться со списком сообщений пользователя, а не со сводкой.
- Публикация — через Trusted Publishing за environment, который одобряет владелец.

**Тег.**
- Тег ставится только на коммит с зелёной dispatch-репетицией через packing, и сообщение
  тега называет этот прогон.
- После публикации тег не двигается никогда: выходит следующий патч.
- До публикации тег можно передвинуть только решением владельца. APT однажды переставил
  v0.2.0: релиз упал на hosted ubuntu (Ok с нулями, небезопасные ref-переносы), публикации
  не было, владелец решил переставить.

**Доказательство изменения CI.** Изменение workflow доказывается прогоном именно того пути,
который изменён, на нужном классе раннера: CI-прогон для `ci.yml`, dispatch для
`release.yml`. Чтения недостаточно.

**Раннеры.**
- Self-hosted раннеры без прав администратора; не держатся службой. Их запускает оркестратор
  по слову владельца, в фоне через `run_in_background` харнесса (Windows — `run.cmd`,
  WSL — `run.sh`), и останавливает после релиза.
- Задачи с GPU — только на теге или dispatch, никогда на коде PR.
- Hosted-раннеры работают на других CPU, поэтому битовые снимки проверяются только на
  эталонной машине. Снимки привязаны к машине, а не к платформе: CRT выбирает
  FMA3-варианты `exp`/`log`, и у APT от одного переключателя сдвигались 38 из 99 ракетных
  случаев. Это объявленное отклонение §12, а не дефект снимка. Запись о битах — запись
  машины.

**Логи.**
- Логи GitHub требуют авторизации. Учётные данные владельца не используются: владельца
  просят вставить лог.
- Публичный API без авторизации быстро упирается в rate limit; APT сжёг его частым опросом.
- Локальные логи раннеров (`_diag`) читаются без сети.

**Заявленная поддержка доказывается запуском** (`costly-mistakes.md`, post-link на
SM_75–90): поддержку архитектуры доказывают компиляцией под неё и запуском результата на
том устройстве, что есть, а не чтением.
