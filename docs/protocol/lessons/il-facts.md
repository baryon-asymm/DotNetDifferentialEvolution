# IL-факты: запрещённые формы, найденные в скомпилированном коде

Источники: **APT** (основной), **CPM**. Касается .NET-деревьев; приём переносим на любой
стек, где можно читать скомпилированный код.

**Живой образец** (APT) — `tests/Protocol.Tests/InvariantTests.cs`, факт
`NoSrcMethodPassesHostMemoryToAnIlgpuTransferByReference`. Он ищет вызовы
`CopyToCPU*`/`CopyFromCPU*` (включая `…UnsafeAsync`) из сборок ILGPU с параметром
`IsByRef`, тип элемента которого не `Span<>`/`ReadOnlySpan<>`. Голый `ref` не пинит
память, и GC сдвигает массив посреди копирования; `in Span<T>` тоже by-ref, но этот
оверлоад пинит. Сообщение называет вызывающий метод и сигнатуру.

**Каркас для любого запрещённого приёма** (APT):
1. набор сборок — из списка узлов дерева, а не набранный руками;
2. обход IL тел методов с операндами-методами (`IlBody` из `Protocol.Tests`);
3. предикат «вызываемый API»: сборка плюс префикс имени;
4. предикат «запрещённая сигнатура или аргумент»;
5. явный allow-list безопасных форм: запрет по списку обходится (`Math.Max` →
   `double.Max`, в IL тот же `max.f64`);
6. отказ на пустом обходе — «no call found: the walk proves nothing». Это нужно **в каждом
   факте**, не только в IL;
7. красный один раз: временно вернуть запрещённую форму и увидеть падение.

Для комплекта — параметризованный помощник
`ForbiddenCalls(assemblies, calleePredicate, signaturePredicate, allowList)` плюс
образец-тест: предикаты задаёт дерево, а обход, отказ на пустом обходе и формат сообщения
даёт комплект. Сделано в `reference/dotnet/` (`ForbiddenCalls`, `ForbiddenCallRule`,
`ForbiddenCallTests`; выключено по умолчанию, включается в `ProtocolConfig`).

**Тот же каркас держит:**
- allow-list `System.Math`/`System.Double`, где `IsNaN`/`IsNegative` разрешены только
  внутри `KernelMath` (APT);
- запрет `float`/`Half` — по опкодам `.r4` и по типам в форме (оба);
- **счётную льготу** (CPM): «ровно одно `conv.r4` в методе `Attempt.AddReal4`». Льгота,
  которая перестала быть нужной, сама краснеет.

**IL-факт защищает от повторения дефекта, а не находит его** (APT). Сам дефект поймали
упавший релиз на hosted CI и детерминированный тест-воспроизведение — `GC.Collect` между
взятием указателя и копированием. Полная защита состоит из трёх частей:
- тест-воспроизведение;
- IL-факт;
- проверка в рантайме: загрузка, которая ничего не записала, отклоняется (sentinel).

**Враждебные входы для «GPU = CPU»** (APT). ILGPU переворачивает сравнение с константой
слева, и `KernelMath.Min(c, NaN)` даёт `c` на CUDA и `NaN` на CPU. Инвариант «GPU = CPU»
проверяют на NaN, ±0, ±inf и с константой в обеих позициях, а не на физических случаях;
плюс проверка исходников на константу слева в упорядоченном сравнении
(`ConstantLeftComparisons`).
